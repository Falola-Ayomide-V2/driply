# Driply

AI-powered personal wardrobe and styling assistant.

## Status

Phase 1 — Foundation complete.

## Stack

- Vite + React + TypeScript
- Tailwind CSS
- Supabase (database backend)
- React Router

## Development

```
npm run dev
npm run build
```

## Structure

```
src/
  components/
    navigation/    Bottom nav + desktop rail
    ui/            Buttons, inputs, states, sheet, header
  features/        Feature modules (stylist, wardrobe, inspiration)
  layouts/         App shell layout
  lib/             Supabase client + database types
  pages/           Route pages
```
